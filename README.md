## 📋 Sobre o Projeto
Este repositório (`Web_portfolio.html`) abriga o código-fonte do meu **Portfólio Pessoal**, desenvolvido como parte de uma atividade prática de desenvolvimento web. O projeto reúne meus códigos em **Python, HTML5, CSS3 e Bootstrap 5**, integrando minha bagagem analítica e de negócios de 9 anos em operações globais com o universo da programação.

O layout foi customizado com a estética **Anime Dark Mode**, utilizando uma paleta refinada em **rosa neon, lilás e dourado**, efeitos visuais em *glassmorphism* e interatividade via JavaScript.

---

## 🛠️ Tecnologias Utilizadas
* **HTML5 & CSS3:** Estruturação semântica, variáveis customizadas (`:root`), gradientes e animações suaves (`hover` e transições).
* **Bootstrap 5.3:** Sistema de grid responsivo, componentes de navegação, cards e barras de progresso estilizadas.
* **Python:** Linguagem base aplicada em scripts de automação e utilitários exibidos no portfólio.
* **Google Fonts (`Cinzel` & `Poppins`):** Tipografia temática combinando elegância e modernidade.
* **JavaScript:** Controle dinâmico de efeitos visuais e interatividade.
* **Git & GitHub Pages:** Controle de versão e hospedagem web gratuita.

## ⚙️ Funcionamento e Seções do Site
O site foi estruturado no formato *Single Page Application* (página única) para uma navegação fluida através de um menu fixo (`sticky-top`):
1. **Perfil (`#perfil`):** Apresentação pessoal em formato de card de personagem, contendo foto oficial do GitHub e resumo profissional.
2. **Atributos & Skills (`#habilidades`):** Seção com barras de progresso divididas entre competências de tecnologia (Python, Web) e de negócios.
3. **Missões & Projetos (`#projetos`):** Grade interativa conectada diretamente aos repositórios públicos no GitHub.
4. **Contato (`#contato`):** Canais diretos para conexão profissional via LinkedIn, GitHub e E-mail.

## ✨ Recursos Novos Adicionados (Além do Modelo Base)
Para garantir a evolução técnica e visual do projeto, foram implementados recursos avançados:
1. **Identidade Visual Anime Dark Mode:** Customização completa da paleta de cores padrão do Bootstrap utilizando tons escuros profundos (`#0d0914`), rosa (`#ff6ec7`), lilás (`#b388ff`) e dourado (`#ffd700`), acompanhado de efeito *glassmorphism* na barra de navegação.
2. **Seção de Status de Personagem (Skills):** Nova seção estruturada com barras de progresso estilizadas para evidenciar competências técnicas e estratégicas.
3. **Efeito de Aura Interativa (JavaScript):** Um botão interativo na barra de navegação (`Aura: ON/OFF`) que ativa e desativa o brilho neon (*glow*) e as sombras dinâmicas dos cards e do avatar.

### Como os recursos foram implementados:
* **Paleta e Glassmorphism:** Foram definidas variáveis globais no CSS (`:root`) e aplicada a propriedade `backdrop-filter: blur(12px)` na classe `.navbar-anime`.
* **Animações:** Utilizou-se `transition: transform 0.35s ease, box-shadow 0.35s ease` nas classes `.project-card` e `.profile-img` com pseudo-classes `:hover`.
* **Botão Aura ON/OFF:** Implementado via JavaScript (`addEventListener('click')`) manipulando dinamicamente as propriedades `boxShadow` e `borderColor` dos elementos no DOM.
