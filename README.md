## 📋 Sobre o Projeto
Este repositório (`Web_portfolio.html`) abriga o código-fonte do meu **Portfólio Pessoal**, desenvolvido como parte de uma atividade prática de web design. O projeto foi construído para unir a minha bagagem profissional de 9 anos em **Comércio Exterior, Transporte Marítimo e Customer Experience** com o universo do desenvolvimento de software e automações.

O layout foi totalmente customizado com a estética **Anime Dark Mode**, utilizando uma paleta refinada em **rosa neon, lilás e dourado**, efeitos visuais em *glassmorphism* e interatividade via JavaScript.

---

## 🛠️ Tecnologias Utilizadas
* **HTML5 & CSS3:** Estruturação semântica, variáveis customizadas (`:root`), gradientes e animações suaves (`hover` e transições).
* **Bootstrap 5.3:** Sistema de grid responsivo, componentes de navegação, cards e barras de progresso estilizadas.
* **Python:** Linguagem base aplicada em scripts de automação e utilitários exibidos no portfólio[cite: 1].
* **Google Fonts (`Cinzel` & `Poppins`):** Tipografia temática combinando elegância e modernidade.
* **JavaScript:** Controle dinâmico de efeitos visuais e interatividade.
* **Git & GitHub Pages:** Controle de versão e hospedagem web gratuita.

---

## ⚙️ Funcionamento e Seções do Site
O site foi estruturado no formato *Single Page Application* (página única) para uma navegação fluida:
1. **Perfil:** Apresentação pessoal em formato de card de personagem, contendo foto oficial do GitHub e resumo profissional.
2. **Atributos & Skills:** Seção com barras de progresso divididas entre competências de tecnologia (Python, Web) e de negócios (Logística, CX).
3. **Missões & Projetos:** Grade interativa conectada diretamente aos meus repositórios públicos.
4. **Contato:** Canais diretos para conexão profissional.
